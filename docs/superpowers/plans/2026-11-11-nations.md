# Nações Rivais (ciclo 4) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Até 4 nações rivais com IA, guerra por declaração, ocupação com dano de guerra, eliminação e fim de partida.

**Architecture:** `GameState.nations[]` guarda o que hoje é só do jogador (recursos, capital, falta de grãos, contador de exércitos); toda regra recebe a nação como último parâmetro opcional (`n = 0`). `hostile()` decide quem luta e corta. A IA (`src/sim/ai.ts`) é o jogador automático dos testes promovido, com pesos por inclinação, chamado nos passos fixos das tropas.

**Tech Stack:** TypeScript, Canvas 2D, vitest.

**Spec:** `docs/superpowers/specs/2026-11-11-nations-design.md`

## Global Constraints
- Números em `balance.ts`:
  - `DIFFICULTY = { easy: 0.7, normal: 1, hard: 1.3 }` (renda dos rivais; o jogador é sempre 1).
  - `WAR = { militarist: 0.15, expansionist: 0.08, strongMult: 2, strongRatio: 1.5, graceMonths: 24 }`.
  - `OCCUPY = { base: 1, garrison: [0, 2, 3, 4], capital: 3 }` (meses).
  - `FORTRESS.claimTiles = 20`.
  - `AI_BENT = { militarist: { garrisonShare: 1/2, margin: 1.5 }, expansionist: { garrisonShare: 1/3, margin: 2 }, industrial: { garrisonShare: 1/4, margin: 3 } }`, `AI = { defendRatio: 0.8, recomposeBelow: 0.5, phaseSteps: 10 }`.
  - `MAX_RIVALS = 4`.
- Nome `"Nação de <capital>"`; inclinações `'militarist' | 'expansionist' | 'industrial'` (Militarista, Expansionista, Industrial).
- Nação = último parâmetro opcional `n = 0` em todo comando, `check*`, custo e contagem. O cliente não muda as chamadas.
- `events` é o feed do jogador: o que é de outra nação só entra se for guerra ou eliminação (`logFor(s, n, text)` loga só se `n === 0`).
- Estado serializável; simulação pura; determinismo 1× = 8×; sorteios só via `makeRng(subSeed(s.seed, ...))`.
- Tasks 1–3: cliente pode ficar com o jogo de um só jogador (só `tsc` limpo). Tasks 4–5: `tests/greedy.ts` vira wrapper da IA. Tudo verde a partir de cada task.

## Review Focus
1. Exército do jogador com linha de suprimento saindo de uma cidade que é conquistada → linha cai, sem reforço nem custo, sem exceção. (Task 3)
2. Nação eliminada no meio de uma batalha → batalha segue/termina sem ids velhos, exércitos dela somem. (Task 3)
3. `moveArmies`/`splitArmy`/`supplyArmy` com id de exército de rival → recusado ou ignorado, nada do rival se mexe. (Task 1)
4. Rival sem dinheiro (renda cortada) por meses → IA não afunda o dinheiro abaixo de zero de forma persistente nem trava. (Task 4)
5. Declaração de guerra entre dois rivais com exércitos lado a lado → batalha começa no passo seguinte; o jogador em paz com ambos, perto, não entra. (Task 2)

### Task 2: Paz, guerra e hostilidade

**Files:** Create `src/sim/war.ts`; Modify `src/sim/{battle,routes,armies,tick}.ts`; Test `tests/war.test.ts`

**Interfaces:**
- Produces: `hostile(s, a: number, b: number): boolean` (`a !== b && (a === -1 || b === -1 || atWar)`); `declareWar(s, n, target, pm?): Result` — recusas `'Nação inválida'` (inexistente ou eliminada, dos dois lados), `'Não pode declarar guerra a si mesma'`, `'Já em guerra'`; efeito: `atWar` dos dois lados, evento `"A Nação de X declarou guerra à Nação de Y"` (sempre no feed), `s.speed = 0` se `target === 0`.
- `aiWarRoll(s, pm, n): void` — mensal, só para rivais; vizinhos = nações com província vizinha de uma província de `n`; carência `s.month - founded < WAR.graceMonths` → nada; Industrial nunca; Militarista `p = 0.15 × (bat(n) ≥ 1.5 × bat(v) ? 2 : 1)`; Expansionista `p = 0.08` só se `bat(n) > bat(v)`; sorteio `makeRng(subSeed(s.seed, \`war:${n}:${s.month}:${v}\`))() < p`.
- Batalha: contato, entrada e dano só entre donos hostis; fim quando não restam dois donos hostis entre si. Fuga para província própria do dono do exército (já é por `owner`).
- Rotas e linhas: `threatMask(s, grid, n)` com exércitos hostis a `n` (cache por nação); `routeGrid(s, pm, grid, n)`; `markCuts` usa a ameaça do dono da rota; `updateSupply` vale para todas as nações (cobertura e ligação da nação dona; desgaste para todos; aviso só do jogador); `reinforcing`/`reinforceStep` pagam do `nations[owner].res`; `refill` em território do dono.

### Task 3: Ocupação, conquista, eliminação e fim

**Files:** Create `src/sim/conquest.ts`; Modify `src/sim/{armies,fortress,tick}.ts`; Test `tests/conquest.test.ts`

**Interfaces:**
- Produces:
  - `occupationStep(s, pm, grid, dt)` no passo fixo, depois da batalha: província com dono `o ≥ 0` onde há exército não em fuga de nação `h` hostil a `o` e nenhum exército não em fuga de `o` → `progress += dt` (cria a entrada; com mais de um ocupante fica o de mais homens); com exército de `o` presente, a entrada fica parada; sem ocupante, a entrada some.
  - `occupyMonths(s, province): number` = `(nível máx. de Guarnição ativa ? OCCUPY.garrison[nível] : OCCUPY.base) + (capital de alguém ? OCCUPY.capital : 0)`.
  - `fall(s, pm, province, n)`: dano de guerra (prédio `level - 1`; N1 ou em obra → `null`; cidade `max(1, level - 1)`, sem obra), cancela `recruiting` e `colonizing` ali, remove rotas com ponta nela, `supply = null` em exércitos com `supply.from === province`, `connected[province] = false`, `owner = n`; eventos (feed do jogador): `"<prov> perdida para a Nação de X"` / `"<prov> tomada da Nação de X"`; se era capital de alguém → `eliminate`.
  - `eliminate(s, pm, loser, by)`: `alive = false`; remove exércitos, recrutamentos, colonizações e ocupações dela; remove `loser` dos `atWar`; demais províncias → neutras (`owner -1`, `city null`, lotes e veios `null`, rotas removidas, `depot` zerado); evento `"A Nação de X foi eliminada pela Nação de Y"`; `result = 'defeat'` se `loser === 0`, `'victory'` se nenhum rival vivo e o jogador vivo.
  - Fortaleza caída → `found(s, id, k)` com `k` = nação com mais homens a ≤ `FORTRESS.claimTiles`; empate: menor id.
  - Painel/IA leem `s.occupations`.

  - Ocupação sem Guarnição cai em 1 mês (`run(0.95)` ainda do dono, `run(0.1)` do ocupante); Guarnição N1/N2/N3 → 2/3/4; capital +3.
  - Ocupante sai → entrada some; volta → recomeça do zero. Exército do dono dentro → `progress` não muda; em fuga → avança.
  - Em paz não ocupa.
  - Ao cair: lote N2 → N1, lote N1 some, veio em obra some, cidade N2 → N1 e N1 → N1; treino ali cancelado; rota com ponta nela removida.
  - Review Focus 1: exército do jogador com `supply.from === prov` e batalha registrada → após `fall`, `supply === null`, `reinforceStep` não cobra nada.

  - Review Focus 2: rival eliminado enquanto um exército dele está numa batalha com o jogador → próximo passo sem exceção, batalha termina, `armyIds` só de exércitos vivos.
  - Fortaleza vai para a nação com mais homens em volta.
  - JSON ida e volta com ocupações.

### Task 5: IA — defesa, recomposição, ataque a nações

**Files:** Modify `src/sim/ai.ts`; Test `tests/ai.test.ts`

**Interfaces:**
- Em `aiStep`, antes da economia:
  1. **Defender:** invasores = batalhões de exércitos hostis em províncias de `n` (ou ocupando). Livres = exércitos de `n` fora de batalha e fuga. Se `batalhões livres ≥ AI.defendRatio × invasores`, manda os livres mais próximos (até somar a razão) ao invasor mais próximo da capital; senão manda todos à capital.
  2. **Recompor:** exército com `men < AI.recomposeBelow × cheio` vai à província própria com Guarnição mais próxima.
  3. **Atacar:** alvos = fortalezas + províncias de nações em guerra com `n`; defesa do alvo = batalhões hostis a ≤ 20 tiles da cidade (mínimo 1); ataca só se `prontos ≥ margin × defesa`; capital inimiga que passa no teste vem primeiro; senão menor defesa, depois mais perto; sempre `supplyArmy`.

- [ ] **Step 1: Testes:**
  - Defende: rival com 4 batalhões livres, invasor de 3 batalhões numa província dele → no próximo `aiStep` os exércitos dele têm caminho até o invasor.
  - Recua: invasor de 10 → exércitos dele seguem para a capital.
  - Recompõe: exército com 40% dos homens vai para província com Guarnição.
  - Margem: Industrial com 5 batalhões não ataca província inimiga com 2 (5 < 3×2); Militarista com 3 ataca (3 ≥ 1.5×2).
  - Partida: 5 nações, 600 meses, 4 sementes, sem exceção; Normal: 1ª guerra entre 20 e 60 meses e ≥ 1 nação eliminada até 400 meses (na média das sementes; teste de ritmo).
